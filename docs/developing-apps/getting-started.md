# Getting Started

An **htmlOS NEXT** app is, in it's code, just a static web app. It can have it's own assets, styles and scripts, but it needs to have an HTML entry point. With this approach, you can run vanilla HTML apps, as well as apps built with frameworks and libraries, like Vite and React.

If you just want to build a simple app, you can read the [creating a simple app tutorial](./tutorial/1-getting-started).

---

We recommend that, if you are building an app from scratch, that you use the recommended stack. This way, we can achieve a consistent look and feel across apps.

These are our recommendations:
- **Framework:** Vite
- **Component Library:** React
- **Language:** TypeScript
- **UI Library:** @htmlos-next/ui
- **API Library:** @htmlos-next/api

The UI Library offers plenty of components to get start building apps with. It is the UI library that the system apps use to achieve their consistent look. To get started with this UI library, read [Getting Started with UI](../packages/ui/getting-started).

The API library gives apps certain functionality over the operating system. To get started with this API library, read [Getting Started with API](../packages/api/getting-started).
